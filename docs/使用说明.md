# 使用说明

面向使用者的操作指南。安装和功能清单见 [README](../README.md)。

---

## 一、安装与首次启动

1. 去 [Releases](https://github.com/lilulj/ai-skill-manager/releases) 下载 `AI Skill Manager-x.x.x-setup.exe`
2. 双击安装。**按用户安装，不需要管理员权限**，可以自己选安装目录
3. 装完桌面和开始菜单会有快捷方式

**先确认本机装了 Node.js 22.20 或更高版本。** 在终端运行：

```bash
node -v
```

没有 Node 也能打开程序、浏览和管理技能，但「检查更新 / 市场 / 安装」这几个功能会灰掉。

首次打开会扫描 `C:\Users\你的用户名\.claude\skills`，把里面所有技能列出来。

## 二、界面速览

```
┌─ 顶栏：搜索 + 功能按钮 ─────────────────────────┐
├─ 左栏 ─────┬─ 中间：技能卡片 ─┬─ 右侧：详情 ────┤
│ 作用域      │                  │ 描述            │
│ 分类        │                  │ 分类/来源/依赖   │
│ 视图        │                  │ 操作按钮         │
└────────────┴──────────────────┴─────────────────┘
```

- **左栏**切换作用域（全局 / 项目）和分类，过滤列表
- **中间**每张卡片是一个技能，点一下在右侧看详情
- **右栏**能看到完整描述、来源、需要的命令行工具，以及所有操作按钮

顶栏最右边的四个小按钮：`中/EN` 切换界面语言、`☾` 切换深浅主题、`⚙` 设置、`↻` 重新扫描。

## 三、日常操作

### 启用 / 禁用

点技能卡片 → 右侧点「禁用」。

技能会被移到 `~/.claude/skills-disabled/`，**文件不会丢**。Claude Code 读不到它，自然就不会被加载。

**什么时候该禁用？** 技能装多了会稀释 AI 的注意力——40 个技能全开着，它每次都要读完 40 份描述才能决定用哪个。做视频时只留视频类，做前端时只留 UI 类，效果更准也更快。

### 编辑

点「编辑」直接改 `SKILL.md`，保存后立刻校验 YAML 格式。保存成功会自动关窗并刷新列表。

### 修复

技能出现红色「异常」时，点「修复」。它会依次尝试：

1. 修正 YAML 里的非法转义（比如双引号里的 `\s`）
2. 补写缺失的 description
3. 把 frontmatter 的 name 改成与目录名一致

**只改文件头部那几行，不动正文。**

### 卸载

点「卸载」，两步确认：

1. 第一步告诉你后果，并显示有没有备份
2. 第二步要**手打技能名**才能解锁删除按钮

可以先点「先备份这个技能」，删错了能在备份里还原。卸载时会自动断开分发到其他工具的链接。

## 四、检查更新

点顶栏「检查更新」，会去各技能的来源仓库查有没有新版本。

结果分三种：

| 情况 | 显示 |
|---|---|
| 全是最新 | 绿色「全部技能已是最新」 |
| 有更新 | 顶部列出技能名，**点名字可以单独更新** |
| 本地技能 | 没有上游来源，本来就没得更新 |

**单个更新**：点顶部的技能名，或者选中技能后点右侧蓝色的「更新」。

**批量更新**：点「更新全部」。**更新前会自动做一次全量备份**，出问题能回滚。

**先看差异再更新**：点「预览」能看到远端版本和本地版本逐行对比，确认没被塞奇怪东西再更新。

## 五、市场与仓库

点顶栏「市场」，面板顶部有两个标签。

### 市场

搜索 skills.sh 上的技能，显示安装量，一键安装。

同一个技能名常有多个来源，标签会区分：

- **superpowers 衍生**：同一份内容的镜像，装哪个都一样
- **RunComfy 系**：功能相同但后端不同

不确定时点「详情」，会显示**内容指纹**——和本机已装的一致就说明是同一份东西，不用重复装。

安装位置跟随左侧作用域：全局作用域装到 `~/.claude/skills`，项目作用域装到该项目的 `.claude/skills`。

### 仓库

登记你本地的其他仓库目录（不限于技能），只做统计，**不会当技能处理、不会改里面的文件**。

每行显示：大小、文件数、git 分支、是否有未提交改动、最后提交时间。

三个操作：

| 按钮 | 作用 |
|---|---|
| **打开** | 资源管理器打开目录 |
| **检查** | git fetch 后对比，显示「落后 N 个提交」+ 本地/远端 commit 哈希 |
| **更新** | git pull（只做快进合并），有百分比进度条 |

底部「检查全部」可以一次查完所有仓库，「移除」只是从列表去掉，**不删任何文件**。

## 六、分发：让其他 AI 工具也能用

点顶栏「分发」。

默认装好的技能只有 Claude Code 能读。这个功能把它们共享给 Codex、Cursor、Gemini CLI 等工具。

1. 选「分发范围」：当前筛选（推荐）或全部
2. 选「同步方式」：链接或复制
3. 在目标工具那行点「连接」

**链接**用的是 Windows 目录联接（junction），不占额外磁盘空间，改了源文件对方立刻同步。**复制**是独立副本，需要重新分发才同步。

连完要**重启对应的工具**才能发现新技能。

豆包这类没有技能目录的，用「导出技能包」生成一份 Markdown 粘贴过去。

---

## 七、归位：收拾装错地方的技能

点顶栏「归位」。

程序会扫描各 AI 工具的技能目录，找出散落在别处的技能，和唯一目录比对后分三类：

| 状态 | 含义 | 能做什么 |
|---|---|---|
| **新增** | 唯一目录里没有 | 移动并指向 / 只移动 |
| **重复（内容相同）** | 两边一模一样 | 合并并指向 |
| **冲突（内容不同）** | 同名但内容不一样 | 查看差异 |

- **移动并指向**：搬进 `~/.claude/skills`，在原位置留一个联接，装它的 AI 还能照常用
- **只移动**：只搬走，原位置不再保留入口

程序**不会自动搬运**，每一项都要你点按钮确认。检测到散落技能时，启动后顶部会提示，按钮会显示数量。

扫描时会自动排除：系统目录（`.system`）、已经是联接的、在 git 仓库里的、没有 `SKILL.md` 的。

## 八、备份与还原

点顶栏「备份」。

### 新建备份

点「立即备份」，可以：

- **填名称**：默认是「手动备份 2026-11-15 16:20」，改成「改文案前」「加新技能前」这种更好认
- **改目录**：备份存到哪由你定，不用挤在 C 盘

### 管理

列表显示时间、备注、技能数、大小。每行两个操作：

- **还原**：恢复到这个时间点（还原前会再自动存一份当前状态，防止还原后想反悔）
- **删除**：删掉这份备份，释放空间

「移除」和「删除」不一样——这里删的是备份文件本身。

### 什么时候会用到

- 批量更新后发现有技能不好用了 → 还原到更新前
- 想不起某个技能原来长什么样 → 找之前的备份对比

---

## 九、套装：一键切换技能组合

点顶栏「套装」。

内置四套：短剧生产包、图像出图包、视频渲染包、前端设计包。

**套装不是新东西，只是一组「哪几个技能开着」的预设。**

- **启用该套装**：把这几个技能打开，其他保持原样
- **只留该套装**：打开这几个，同时关闭其余全部

每个套装旁边有状态标签：`全部已启用` / `部分启用 4/6` / `全部未启用`。被禁用的技能名会标黄。

已经全部启用的套装，「启用」按钮会置灰——避免重复操作。

## 十、项目作用域

左侧「作用域」点「+ 添加项目」，选一个文件夹，就能管理**那个项目自己的** `.claude/skills`。

支持两种结构：

- 标准项目：`你的项目\.claude\skills\`
- 技能目录本身：直接选一个里面都是 `技能名/SKILL.md` 的目录

项目里的启用/禁用独立于全局，互不影响。项目里的「预览更新」需要项目根目录有 `skills-lock.json` 才能用。

---

## 十一、设置

点顶栏 `⚙`。

| 项 | 说明 |
|---|---|
| **关闭窗口时** | 收进托盘（后台继续跑）或直接退出 |
| **开机自启** | 开机后只在托盘启动，不弹窗口（打包版生效） |
| **自动检查更新** | 每隔多少小时查一次，设 0 关闭 |
| **备份目录** | 备份存哪，可随时改 |
| **数据目录 / 技能目录** | 一键打开对应文件夹 |

## 十二、常见问题

**Q：关掉窗口后程序还在跑？**
是的，默认收进托盘（右下角）。要完全退出，用托盘图标右键 → 退出，或在设置里改成「直接退出」。

**Q：技能列表是空的？**
检查 `C:\Users\你的用户名\.claude\skills` 是否存在且有内容。如果技能在别的地方，用「归位」扫一下，或者用左侧「+ 添加项目」把它加进来。

**Q：点「检查更新」很慢？**
第一次要跑 `npx skills check`，和所有来源仓库通信，通常 20~30 秒。之后会缓存。

**Q：更新后技能坏了怎么办？**
去「备份」里还原到更新前。批量更新会自动备份，单个更新前建议手动备一次。

**Q：为什么有些技能没有「预览」？**
没有上游来源的本地技能没法对比。项目里的技能还需要项目根目录有 `skills-lock.json`。

**Q：卡片上显示「缺 belt / 缺 runcomfy」是什么意思？**
这个技能需要对应的命令行工具，但本机没装。点顶栏「体检」能看到具体是哪个技能需要，并有一键安装入口。

**Q：装到其他工具的技能，这里能看到吗？**
能。用「归位」扫描，或者看「市场 → 仓库」。

**Q：会不会误删我的技能？**
所有删除都需要二次确认（手打技能名）。禁用只是移动目录，不是删除。建议第一次用之前先做一次备份。
